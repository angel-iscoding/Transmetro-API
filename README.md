# Transmetro-API

Backend system for real-time bus tracking developed with **NestJS** and **Hexagonal Architecture**. Provides RESTful APIs for geolocation, route management, and push notifications.

## Technology Stack
- **Framework**: NestJS with TypeScript
- **Architecture**: Hexagonal (Ports & Adapters)
- **Databases**: MongoDB (geospatial) + PostgreSQL (transactional)
- **External APIs**: Google Maps Platform (Geocoding, Routes)
- **Containerization**: Docker & Docker Compose
- **Authentication**: JWT with roles
